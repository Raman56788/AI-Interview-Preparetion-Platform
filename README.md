# AI Interview Preparation Platform 🚀

An AI-powered interview preparation platform that helps users practice interviews, improve communication skills, and prepare for technical rounds.

## Features

- User Authentication
- AI-based Interview Practice
- Resume Analysis
- Coding Practice
- Interview History Tracking
- User Profile Management

## Tech Stack

Frontend:
- React.js
- JavaScript
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

## Installation

Clone the repository:

git clone https://github.com/Raman56788/AI-Interview-Preparetion-Platform.git

Install dependencies:

npm install

Run project:

npm run dev
